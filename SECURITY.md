# Sicherheitslücken melden

Bitte melde Sicherheitslücken **nicht** als öffentliches Issue, damit sie nicht ausgenutzt werden können, bevor sie behoben sind.

So geht's:

1. Im Repository oben auf **Security** klicken.
2. **Report a vulnerability** wählen und die Lücke beschreiben: Was kann passieren, wie lässt es sich nachvollziehen, welche Version ist betroffen?

Die Meldung ist nur für die Betreuer des Projekts sichtbar. Wir melden uns so bald wie möglich und veröffentlichen eine korrigierte Version.

## Unterstützte Versionen

Sicherheitskorrekturen gibt es nur für die jeweils neueste Version.
